# 🏰 Medieval Scene — React Three Fiber Experience

An immersive medieval scene built with **Three.js**, **React Three Fiber**, and **@react-three/drei**, featuring animations, dynamic weather conditions, day/night cycles, and engaging visual elements. Prepare to explore a magical 3D world right in your browser!

🌐 Live Demo
You can view the live application here: https://r3f-medieval-scene.vercel.app/

---

## ✨ Key Features

### ⚔️ Interactive Medieval 3D Scene

- Imported 3D models with realistic animations.
- Detailed textures to create an authentic atmosphere.
- 3D and 2D UI elements (floating texts, instructions, etc.).

### 🌦️ Dynamic Weather System

- ☀️ **Sunny** — Clear day with bright lighting.
- ☁️ **Cloudy** — Soft clouds cover the sky.
- 🌧️ **Rainy** — Persistent rain with a wet environment.
- ⛈️ **Storm** — Realistic lightning and thunder sound effects.

### 🕰️ Day Cycle Phases

- 🌅 **Morning**
- 🌞 **Afternoon**
- 🌇 **Sunset**
- 🌃 **Evening**
- 🌌 **Night**

Each phase changes the lighting, sky colors, and shadows to simulate the passage of time in real-time or progressively.

### 🚀 Technical Details

- `react-three/fiber` for reactive WebGL rendering.
- `@react-three/drei` for advanced utilities and effects.
- ScreenLoader with smooth transition on load.
- Full camera control with limited zoom and smooth navigation.
